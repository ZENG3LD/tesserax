# tesserax

Core of a back-office library family built on the single-writer core discipline. This release carries the contract module `swc` — command, effect, observation and event envelopes; a bounded, non-blocking command port (`Handle` / `KernelPort` / `Port`); a lock-free `ArcSwap` snapshot edge with a bounded event-log ring and per-subscriber queues that disconnect slow consumers; `resync` with explicit gap detection; and `SnapshotCache` for consumers — plus small pure types shared by the rest of the family: `Tier`/`Scope`, `Principal`, the `AuditSink` seam, CIDR and trusted-proxy helpers, `Published<T>`/`Flags`, and a bounded `LruCache`. A default-on `server` feature adds the shell half: a satellite-agnostic `ServerBuilder` over axum with a route table, fixed `LayerStage` slots and `ServerPlugin`s that other crates use to add authentication, security middleware and the like, built-in `/health`, `/livez`, `/readyz` and `/admin/drain` probes, and lifecycle primitives (hooks, background tasks, graceful shutdown, drain). It also holds the family's single constant-time compare and HMAC-SHA256 (`ct`). With `default-features = false` it depends only on `arc-swap`, `thiserror`, `sha2` and `subtle` and compiles for `wasm32-unknown-unknown`; the optional `serde` feature adds wire derives.
