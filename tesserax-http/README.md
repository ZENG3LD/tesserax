# tesserax-http

The HTTP surface of servers built with `tesserax`. `DocRouter` records every route with a mandatory description and its tier, so the server's route table, the auth gate and the generated OpenAPI 3.1 document all come from the same calls that mount the handlers. `SseHub` gives each event an id and resumes after `Last-Event-ID` without duplicates or gaps (or announces `resync` when the history no longer covers the gap); `WsHub` publishes by topic with a ping liveness check. The `guard` module has CORS, security headers, double-submit CSRF, IP allow / deny lists, a per-address concurrency cap, per-address and per-tier rate limits, idempotency keys and webhook signature checks; HMAC and every secret comparison go through `tesserax::ct`. ETag, Server-Timing, traceparent, an access log, static directories and a small dashboard page are included. `HttpExt` installs all of it on a `ServerBuilder` at fixed layer stages. Optional features: `signing` (signed responses with a `tesserax-secrets` identity), `cors-proxy` (a same-origin proxy with an upstream host allowlist) and `metrics` (Prometheus).
